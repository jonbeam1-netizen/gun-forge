Using it in ZED ZONE

  1. Download the ZIP and unzip it somewhere easy, like your Desktop.
  2. In the game open MOD Hub → MOD Editor → NEW, then Import Template and pick a gun close to yours so the stats start sensible.
  3. In [ TEXTURE ] choose IMPORT PNG. The editor asks for a file path: in File Explorer, Shift + right-click the PNG and pick Copy as path, then paste it (remove the quotes if it complains).
  4. Import _full.png as the Full Image. Import the other slot PNGs (main_body, barrel, aimer, gunstock, magazine, moving_part) into their matching slots if your gun uses them.
  5. Keep PPU at 64 for 1× exports. Use layout.txt for the Gun Point and mount offsets, then tweak them while watching Generate Preview.
  6. Set damage and ammo in [ PARAMS ], then SAVE. Share it from Workshop → Publish Center.
